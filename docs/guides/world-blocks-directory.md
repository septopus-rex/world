## 三、大型 3×3（九宫格）复合密室布局

关卡文件：[`client/core/src/levels/escape_room_3x3.level.json`](file:///Users/fuu/Desktop/AI/world/client/core/src/levels/escape_room_3x3.level.json)

```

  [2030, 2030] (SW: 密室前厅·起点) ──   [2031, 2030] (S: 机关长廊)        ──   [2032, 2030] (SE: 机关水室)
                                                                                  → 东 (X+)
```

### 九大房间探索与跨块联动

1. **西南前厅 `[2030, 2030]`（起点）**：探险家 NPC 讲解情报，地面拾取初始铜钥匙（`tpl_1`）。
2. **南向机关长廊 `[2031, 2030]`**：地刺伤害陷阱，踩地砖压力板**跨块升起东侧水室大门**（`flags.corridor_gate_open`）。
3. **东南机关水室 `[2032, 2030]`**：水池旁点击排水阀门，水位退去，拾取水底玄铁钥匙（`tpl_2`）。
4. **西向军械营 `[2030, 2031]`**：击败骸骨守卫 NPC，掉落暗影宝珠（`tpl_3`）。
5. **西北高空跳台室 `[2030, 2032]`**：悬浮跳台攀爬至 4 米高台，踩下天闸拉杆破除封印（`flags.skylight_unlocked`）。
6. **东向炼金工坊 `[2032, 2031]`**：调配古法能量药剂，阅览实验日志。
7. **中央能量大殿 `[2031, 2031]`（核心枢纽）**：注入玄铁钥匙与暗影宝珠，**跨地块升起北面终极大门（`adj_2031_2032_161_0 moveZ 5.0`）**！
8. **北向大逃脱圣殿 `[2031, 2032]`（终点）**：走上逃生祭坛，达成 `escape_3x3_victory` 全境通关！
9. **东北藏宝金库 `[2032, 2032]`**：荣耀展厅，获取远古金杯与通关纪念。
