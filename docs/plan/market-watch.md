## 2026-08-04

搜索关键词：3D 虚拟世界引擎 + ECS/TypeScript + 区块链可选/UGC 体素世界，中英文各角度。

- **Openverse**（`openverse.club`）—— 浏览器直玩的 voxel MMO，跑在 Solana 上，无需下载，可挖矿/建造/种田/地块确权。2026-06 才在 X 起号，是很新的项目，token 24 小时内持有人 13→553，明显刚 launch。
  产品形态（浏览器直开、体素世界、可建造、链上确权）与 world 早期"链原生"阶段的定位接近，但工程路线相反：Openverse 公开信息里看不到引擎架构/ECS 设计，主要信息来源是价格预测站和 X 推广贴，是 **token 驱动**的加密项目；world 是**链完全解耦成可选发布插件**（engine/client 零 `@solana` 依赖），工程先行、链是可选项。目前判断：产品表面像，路线不同，非直接竞品。
- **PolyEngine**（`poly-engine.github.io`）—— TypeScript + ECS 的 Web3D 引擎（WebGPU），技术栈层面与 world 引擎（TS ECS）同类，但没有体素世界/区块链相关信息，纯引擎框架，无产品定位重合。

**结论**：未搜到与 world「TS ECS 引擎 + 无链 PWA 客户端 + 链可选发布插件 + SPP 协议式内容生成」这一组合高度重合的项目。Openverse 是当前产品形态最接近的新项目，但路线是加密炒作而非引擎工程，暂不构成直接竞品压力。
