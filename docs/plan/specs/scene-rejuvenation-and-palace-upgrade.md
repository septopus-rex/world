# 场景次世代重塑与故宫大关升级规范 (Scene Rejuvenation & Palace Upgrade Spec)

> **状态**：规范落地 · **目标版本**：v0.2+ · **首选实施**：`palace.level.json` 6×6 连片宫殿次世代重构
> **定位**：在 PBR 材质通道、GTAO 接触阴影、Bloom 泛光及模组化 3D 资产库完备后，将 3D 虚拟世界从基础方块体素全面提升至次世代写实与古典意境并存的高精场景。

---

## 1. 目标与背景

随着渲染引擎完成了 PBR 多通道贴图管线（Normal / Roughness / Metalness / AO / Emissive）、后处理链（GTAO 接触阴影、Selective Bloom、ACES 色调映射）与首批模组化 3D 预制件（Modular Prefabs）的建设，3D 虚拟世界的底层表现力已具备次世代承载能力。

然而，现有多数大场景（如 6×6 连片核心关卡 `palace.level.json`）仍停留在早期以纯色块为主的体素搭建形态，存在：
1. **表面平淡**：大殿墙面、庭院地砖多为无纹理纯色或基础漫反射贴图，缺乏微表面法线凹凸与光泽反差；
2. **边缘生硬**：台阶、栏杆、水池边沿为 90° 锐角方块拼装，缺乏物理倒角高光与构件层次；
3. **生态空旷**：庭院、回廊缺少多层次园林绿化（松树、灌木、盆栽、草丛）与微观陈设道具（宫灯、长椅、石雕、路沿）。

本规范确立场景重构的通用准则，并以 **故宫大关（`palace.level.json`）** 为第一标杆进行全量次世代质感升级。

## 3. 故宫 6×6 连片大场景（`palace.level.json`）重构方案

遵循 `palace-stress-level.md` 的边界墙单侧归属（N+W 归属原则）与大门骑缝规则，在不破坏流式性能与测试断言的前提下，对 36 块区域进行针对性升级：

```
 y=1105 │ NW·客房小楼 │ 藏书阁   │ 影音厅   │ 留言厅   │ 展廊     │ NE·御膳房
 y=1104 │ 麻将房      │ 西回廊   │ 北回廊   │ 北回廊   │ 东回廊   │ 射击场
 y=1103 │ 台球房      │ 西回廊   │ 御水池   │ 御花园   │ 东回廊   │ 谒见大殿
 y=1102 │ 德州房      │ 西回廊   │ 御水池   │ 御花园   │ 东回廊   │ 演武场
 y=1101 │ 叠叠乐房    │ 西回廊   │ 南回廊   │ 南回廊   │ 东回廊   │ 皇家宝库
 y=1100 │ SW·西南角楼 │ 门房     │ 午门(西) │ 午门(东) │ 御马监   │ SE·东南角楼
          x=2100       x=2101     x=2102     x=2103     x=2104     x=2105
```

### 3.1 南门门面（y=1100）
- **[2102..2103, 1100] 午门大门**：
  - 门柱升级为 `column-pillar`（64），大门拱顶采用 `arch-gate`（65）对齐骑缝；
  - 进门台阶与通道两侧布置雕花栏杆 `fence-railing`（66）与路沿石 `curb-edge`（80）；
  - 门前立置两盏发光宫灯 `lantern-lamp`（67），地表铺设 PBR 青砖与汉白玉石道。
- **[2100, 1100] & [2105, 1100] 西南/东南角楼**：
  - 观景台外围加装木石护栏与远眺宫灯，楼梯采用倒角踏步。

### 3.2 露天核心内院（[2102..2103, 1102..1103]）
- **皇家御水池（[2102, 1102..1103]）**：
  - 环池铺设一整圈白玉石栏杆 `fence-railing`（66）与倒角石边 `curb-edge`（80）；
  - 水面保留 a5 动态水体，中央水景搭配微型景观石与石灯；
  - 岸边布置休息长椅 `bench-chair`（68）与石径。
- **皇家御花园（[2103, 1102..1103]）**：
  - 点缀多株苍劲松树 `pine-tree`（70）与灌木 `bush-shrub`（71）；
  - 树下散布地表草丛 `grass-clump`（81）与青石小径；
  - 摆放陶瓷景观盆栽 `plant-pot`（69）与夜行宫灯 `lantern-lamp`（67）。

### 3.3 环形回廊（12 块廊道）
- 回廊面向内院的开敞面全量安装倒角立柱 `column-pillar`（64）与半高护栏 `fence-railing`（66）；
- 走道地面铺设带有法线凹凸的木质地板（52/74/75）与石板路；
- 廊檐悬挂古典宫灯 `lantern-lamp`（67），形成深邃而典雅的纵深光影连廊。

### 3.4 东翼 RPG 殿堂（x=2105, y=1101..1104）
- **[2105, 1103] 谒见大殿**：
  - 御座后方立起九曲金龙屏风 `oriental-screen`（55）；
  - 御台台基铺设汉白玉石雕与两侧引路宫灯。
- **[2105, 1101] 皇家宝库**：
  - 强化地牢石砖材质（56/76/77），条件开门机构保留原生动画。

### 3.5 北翼文博四厅（y=1105）
- **[2101, 1105] 藏书阁**：书架全面覆盖高精书籍贴图（62），搭配红木案台与温暖照明。
- **[2102..2104, 1105] 影音厅、留言厅、展廊**：展台基座与立面统一赋予 PBR 石材质感。

## 4. 性能预算与流式不变性守则

1. **流式窗口限制**：
   - 保持关卡声明 `"extend": 2`（5×5 常驻窗口），确保动态装载与驱逐循环依然严格受控。
2. **Draw Call 与几何复用**：
   - 所有新增 Prefab 构件严格复用 `demo.manifest.json` 注册的共享资源 ID（64~81），由 `ResourceManager` 统一管理生命周期与引用计数。
3. **碰撞体完整性**：
   - 所有门洞、走廊保持顺畅通行（`walkUntil` 测试路径上零阻挡）；
   - 水池边缘与观景台护栏配齐 `b4` 碰撞体，防止坠落或卡穿。
